# Hillis Gartenparty

Einladungsseite im Stil von party-2026 – in Türkis mit Leo-Muster, Dreiecken (wie Hillis Tattoo), Popchor-Noten und einem Sticker „Laut für Demokratie“.

## Noch offen (gelb-gestreifte Platzhalter auf der Seite)
- Alter (XX) in der Überschrift
- Einladungstext
- Datum, Uhrzeit, Rückmeldefrist
- Adresse des Schrebergartens
- Ablauf / Uhrzeiten
- Toilette, Wasser, Strom vor Ort
- Fotos für „Damals & heute“

## Anmeldung
Das Formular fragt: Name, Zu-/Absage, Erwachsene, Kinder, Buffet (Kuchen/Salat/nein),
Übernachtung im Zelt (Personen, eigenes Zelt ja/nein) und Kommentar.
Solange `ZIEL_URL` im Skript leer ist, läuft das Formular im Testmodus und speichert nichts.
Für echte Anmeldungen eine Google-Tabelle mit Apps Script anlegen (wie bei Christoph)
und die Web-App-Adresse bei `ZIEL_URL` eintragen.
